# GhostAssist AI (Smog AI Clone) - Live Voice Edition

GhostAssist AI is a professional, discreet desktop assistant designed for real-time interview and meeting support. Inspired by advanced real-time AI tools like Smog AI, it **listens to the speaker in real-time** via your microphone, converts speech to text, and instantly provides structured talking points and answers.

## 🚀 Key Features

- **Real-Time Voice Listening**: Uses speech-to-text (`speech_to_text`) to automatically hear what the interviewer or speaker is saying.
- **Stealth / Ghost Mode**: Compact, dark-themed UI designed to sit quietly on your screen without interfering with your work or appearing on screen shares.
- **Real-Time AI Intelligence**: Powered by OpenAI (`gpt-4o`) to generate precise, professional answers tailored to your interview or meeting context.
- **Automatic Meeting Notes**: Every question heard and answer generated is automatically cataloged in the meeting notes panel.

## 📦 Getting Started & Usage

1. **Clone & Run**:
   ```bash
   git clone https://github.com/ahmedemadm90/ghost-assist-ai.git
   cd ghost-assist-ai
   flutter pub get
   flutter run -d windows # or macos
   ```
2. **Configure API Key**: Enter your OpenAI API Key in settings.
3. **Activate Live Listening**: Click the microphone icon in the app bar. The app will start listening to the speaker, automatically transcribe their questions, and send them to the AI to display expert answers instantly on your screen!
